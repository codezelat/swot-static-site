# SWOT.lk search strategy

Research date: 27 August 2026

This plan maps search intent to useful pages. It does not use keyword repetition as a ranking tactic, and it does not assume that publishing a page guarantees a ranking. Search performance will depend on technical health, content quality, competition, authority, local signals, user response and continued improvement after launch.

## Search landscape observed

The live search pass covered digital marketing, social media marketing, content creation, performance marketing, SEO, Google Ads, branding, web design, influencer marketing, video production, TikTok and e-commerce marketing in Sri Lanka.

Patterns found across prominent results:

- [CeyagMark](https://ceyagmark.com/) leads with a specific commercial position, public method and measurable outcomes.
- [Cypher360](https://cypher360.lk/social-media-marketing-sri-lanka) uses a dedicated exact-intent social media service page, platform coverage and group context.
- [Ceylond](https://www.ceylond.com/services/social-media) uses dedicated service pages, starting-price information and clear sub-services.
- [Kuha Studio](https://kuhastudio.com/) uses a narrow social-first position, strong local language and end-to-end production coverage.
- [Arkam Kabeer](https://heyarkam.com/) uses specialist authority, campaign categories and detailed paid-media service coverage.
- [Fluencr](https://fluencr.io/about) explains a specific creator-market problem and supports influencer-related informational intent.
- [Vision Works](https://www.visionworkslk.com/) builds production authority through a focused positioning and a visible portfolio.
- [MediaFirst](https://mediafirst.lk/) combines multilingual capability, in-house production and institutional trust signals.
- [Clutch Sri Lanka](https://clutch.co/lk/agencies/digital-marketing) captures comparison intent with category, location, service and review data.

The common weaknesses are repeated generic claims, unsupported No. 1 language, invented-looking statistics, crowded homepages, duplicated location copy and shallow service descriptions. SWOT should avoid all of these.

## Technical search foundation

- Next.js App Router with statically generated service, platform, industry, location and insight pages
- Unique titles, descriptions and canonical URLs
- `Organization`, `ProfessionalService`, `Service`, `FAQPage`, `Article` and breadcrumb structured data
- XML sitemap covering every indexable page
- Robots rules that allow public content and block the contact API
- Optimised local WebP imagery with descriptive alternative text
- Mobile-first responsive layouts and motion-reduced mode
- No fabricated reviews, ratings, awards, clients, statistics or case studies
- Server-validated Turnstile on the enquiry route
- Resend email delivery with user-friendly failure handling

## Post-launch operating plan

1. Verify the domain in Google Search Console and Bing Webmaster Tools.
2. Submit `https://swot.lk/sitemap.xml`.
3. Confirm canonical, structured data, status codes and indexability on the live domain.
4. Create and complete the real Google Business Profile only when the approved address and operating details are confirmed.
5. Publish real project evidence with client permission. Include the baseline, intervention, period, data source and result.
6. Review query and page data monthly. Improve pages that earn impressions but weak clicks, and content that attracts the wrong intent.
7. Earn relevant links through useful research, partnerships, local organisations, expert contributions and work worth referencing.

## Content rules

- Write for the person making the decision, then make the search intent explicit.
- Do not invent performance numbers, named clients, testimonials, certifications or awards.
- Do not create copied city pages.
- Do not publish mass-generated articles without factual and editorial review.
- Keep the homepage visually concise. Put search depth in the page that owns the intent.
- Preserve account ownership, data ownership and honest limitations in service copy.
